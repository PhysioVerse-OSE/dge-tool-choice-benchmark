# Tool Choice Matters: Reproducible Code and Figure Workflows

This repository contains the analysis code used to generate the figures for the manuscript:

**Tool Choice Matters: Evaluating edgeR vs. DESeq2 for Sensitivity, Robustness, and Cross-Study Performance**

The study compares `edgeR` and `DESeq2` across RNA-seq datasets covering viral infection, bacterial infection, and fibrotic lung disease. The analyses include sample-size sensitivity, outlier robustness, within-dataset classification of tool-specific genes, pathway-level concordance, training-gene selection for cross-study validation, and cross-study SARS-CoV-2 prediction.

The repository is organized by figure. Raw count matrices and most generated intermediate CSV files are not included because they can be large and should be downloaded or regenerated by the user.

## General input format

Most scripts expect a CSV file with genes as rows and samples as columns:

```text
Gene Symbol,Control (1),Control (2),Treatment (1),Treatment (2),...
GENE1,10,15,42,38,...
GENE2,0,1,5,7,...
```

Rules:

1. The first column must be named `Gene Symbol`.
2. Every sample column must use the format `GroupName (sample_number)`.
3. The group name is the part before the space and parentheses.
4. Counts should be raw integer gene counts, not TPM, FPKM, CPM, or normalized values.
5. Keep group names exactly as listed below because the scripts use those names.
6. Remove duplicated or unsupported gene symbols before final analysis, or keep the highest total-count duplicate if following the scripts.

Use R 4.4 or newer when possible. The manuscript used current Bioconductor workflows, including `edgeR` v4.4.2 and `DESeq2` v1.46.0.

## Figure 1 workflow: RSVB sample-size sensitivity and outlier robustness

Folder:

```text
figure 1/
```

Required input file placed inside `figure 1/`:

```text
GSE196134-Ready-45.csv
```

Required group columns:

```text
Control (1), Control (2), ..., Control (45)
RSVB (1), RSVB (2), ..., RSVB (45)
```

Run from inside `figure 1/`:

```bash
python 00_generate_figure1_inputs.py --input GSE196134-Ready-45.csv --outdir figure1_inputs --seed 12345 --subsample-reps 20 --swap-reps 20
Rscript 01_run_dge_tools.R figure1_inputs figure1_dge_results
python 02_summarize_figure1_results.py --results-dir figure1_dge_results --outdir figure1_summary --p-cut 0.05 --logfc-cut 1
python 03_plot_figure1_summaries.py --summary-dir figure1_summary --outdir figure1_plots
```

Expected output folders:

```text
figure1_inputs/
figure1_dge_results/
figure1_summary/
figure1_plots/
```

Main outputs:

```text
figure1_plots/Figure1_panels_i_j_revised.png
figure1_plots/Figure1_panels_i_j_revised.pdf
figure1_plots/panel_i_directional_overlap.png
figure1_plots/panel_j_outlier_jaccard.png
```

Notes:

- `00_generate_figure1_inputs.py` creates repeated random subsamples and sample-swapped datasets.
- The random seed is fixed at `12345` for reproducibility.
- `01_run_dge_tools.R` runs both `edgeR` and `DESeq2` on all generated datasets.
- DEGs are summarized using Bonferroni-adjusted `p < 0.05` and `|log2FC| > 1`.

## Recommended run order for a complete reproduction

A complete run from downloaded count matrices should follow this order:

1. Format the downloaded count matrices into the required `*-Ready.csv` or `*-original.csv` files.
2. Run `figure 1/` to regenerate the RSVB sample-size and outlier analysis.
3. Run the five dataset pipelines in `figure 2 and 3/` to regenerate significant DEG files and classification outputs.
4. Run `figure 2 and 3/consistent_figures_2_3.py` to regenerate `Main-2` and `Main-3`.
5. Use the significant DEG files from step 3 to run pathway enrichment and create `pathway_enrichment_outputs_v3/`.
6. Run `figure 4 and 5/make_selected_pathway_difference_bubbleplot.py` to regenerate the pathway figures.
7. Generate the SARS-CoV-2 DGE files required by `figure 6/` and `figure 7/`.
8. Run `figure 6/make_cross_study_venn_single_figure_balanced.py` to regenerate the training gene-selection figure.
9. Run `figure 7/Figure 7.py` to regenerate cross-study classification outputs and `Main-4`.

## Naming convention for DGE result files

For cross-study scripts, use this exact naming style:

```text
EdgeR-<DATASET>.csv
DESeq2-<DATASET>.csv
```

Example:

```text
EdgeR-GSE152418.csv
DESeq2-GSE152418.csv
```

Required columns:

```text
GeneSymbol, logFC, FDR
```

Optional but useful columns:

```text
PValue, Bonferroni_pvalue
```

## Thresholds used in the manuscript

| Analysis | Threshold |
|---|---|
| Figure 1 sample-size and outlier analysis | Bonferroni-adjusted `p < 0.05` and `|log2FC| > 1` |
| Figures 2 and 3 within-dataset DEG/classification analysis | Bonferroni-adjusted `p < 0.05` and `|log2FC| > 1` |
| Figures 4 and 5 pathway enrichment | Enriched pathways with FDR `< 0.05` |
| Figures 6 and 7 cross-study SARS-CoV-2 analysis | Gene-level FDR `< 0.05` and `|log2FC| > 1` |

```
